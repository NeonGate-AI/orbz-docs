# Workflow Skills Map

Local skills are repository-scoped procedures. They are intentionally composed
rather than loaded all at once.

## User-directed delivery skills

| Skill | Use |
|---|---|
| `to-spec` | Turn an agreed change into a durable numbered spec. |
| `to-tickets` | Split a ready spec into vertical implementation slices. |
| `implement` | Execute an approved spec and collect evidence. |
| `spec-driven-development` | Apply the complete spec lifecycle. |

## Model/reviewer skills

| Skill | Use |
|---|---|
| `context-engineering` | Select and maintain the smallest useful context. |
| `documentation-and-adrs` | Write durable documentation and ADRs. |
| `tdd` | Drive behavior through an observable test seam. |
| `code-review` | Review standards and spec fidelity independently. |
| `frontend-ui-engineering` | Change Nextra/React UI without semantic regressions. |
| `accessibility` | WCAG 2.2 AA analysis and remediation. |
| `seo` | Technical/on-page documentation SEO. |
| `performance` | Diagnose rendering/resource performance. |
| `core-web-vitals` | Reason about LCP, INP and CLS evidence. |
| `best-practices` | Security and resilient web-platform review. |
| `web-quality-audit` | Combine SEO, A11y, performance and best-practice evidence. |

The upstream `NeonGate-AI/skills` repository is provenance and inspiration. The
vendored/local files under `.agents/skills/` are normative for this repository.
