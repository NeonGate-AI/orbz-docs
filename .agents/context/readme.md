# Context Map

Load context by question, not by habit. The goal is to keep agent context small
while preserving the facts needed to make a correct change.

| Need | Read |
|---|---|
| Repository ownership, commands, stack | `repository.md` |
| Nextra route/content/navigation structure | `content-architecture.md` |
| Current documented Orbz public API snapshot | `orbz-public-contract.md` |
| SEO, A11y, CWV evidence rules | `web-quality.md` |
| How local skills compose | `workflow-skills.md` |
| Delivery lifecycle overview | `workflows/overview.md` |
| Documentation-specific workflow | `workflows/docs.md` |
| Performance engineering principles | `addy-osmani.md` |

Context records facts and vocabulary. Normative constraints belong in `rules/`;
consequential trade-offs belong in `adrs/`; bounded behavior changes belong in
`specs/`.
