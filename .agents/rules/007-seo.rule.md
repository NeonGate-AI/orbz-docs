# Technical SEO

- Every intended public documentation route must be indexable unless a spec says otherwise.
- Page canonicals are self-consistent and resolve beneath `siteConfig.url`.
- `robots.ts` must advertise the canonical sitemap.
- `sitemap.ts` covers every intended indexable content route without alternate-host duplicates.
- Page titles and descriptions are unique enough to identify the page's task.
- Root Open Graph/Twitter metadata provides safe defaults; page metadata may refine it.
- Structured data is allowed only when visible page content satisfies the schema's eligibility.
- SEO review never promises rankings, indexing time or traffic gains.
