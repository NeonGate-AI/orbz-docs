# Writing for Agents

Assign each fact or requirement to its existing owner: context for facts, rules
for constraints, ADRs for consequential decisions, specs for change contracts,
skills for procedures and workflows for reusable sequences. Link to that owner
instead of repeating its text in multiple layers.

Keep AGENTS.md as a concise router. A pointer states when its target is needed.
Put mode-specific detail behind a relevant link; do not load every reference for
an ordinary task. Check paths against the current tree before publishing them.

Preserve user choices and existing authorization. Completion criteria must name
observable evidence rather than asking the next agent to merely be thorough.
Remove stale commands and application assumptions when source proves they no
longer apply. Update the appropriate catalog and deterministic checker together.

Completion: another agent can locate the governing contract, execute the intended
procedure and distinguish completion from pending evidence without the chat.
