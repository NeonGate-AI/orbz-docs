# Orbz Docs Context Pointer

Canonical repository context lives under `.agents/context/`.

Start with:

- `.agents/context/repository.md` for ownership and technology boundaries.
- `.agents/context/content-architecture.md` for Nextra content organization.
- `.agents/context/web-quality.md` for SEO, accessibility and performance evidence.
- `.agents/specs/readme.md` for active and historical work contracts.

`AGENTS.md` is the executable entry point for coding agents. This file exists as
a stable short pointer for tools and humans that look for a root context file.
